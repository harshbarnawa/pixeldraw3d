# pixeldraw3d ✦

Draw on a 2D pixel slate and watch every pixel pop into a 3D cube.

- 🎨 **Pixel editor** — draw / erase / bucket fill, mirror symmetry, presets, undo/redo
- 🖼 **Image → pixel converter** — drop any photo, turn it into a pixel grid, cube mode for vivid cube-art colors
- 💾 **Saved designs** — stored in the browser, with export/import as JSON
- 🎨 **Color studio** — paint-style color dialog, custom colors, shared palette
- ✨ **Pastel pixel theme** — chunky pixel UI, single-page layout

## Run it

```bash
npm install
npm run dev
```

## Stack

- React 19
- Three.js via @react-three/fiber + @react-three/drei
- Vite 8
